아트로그(art info) 개인정보처리방침

시행일자: 2026년 9월 13일

아트로그(이하 "앱")는 전시·공연 정보 조회, 보관함(북마크), 관람후기 작성 기능을 제공하는 개인 개발 애플리케이션입니다. 본 방침은 앱이 어떤 정보를 어떻게 다루는지 안내합니다.

1. 회원가입 및 개인 식별정보

앱은 별도의 회원가입·로그인 기능이 없으며, 이름·이메일·전화번호 등 사용자를 식별할 수 있는 개인정보를 수집하지 않습니다.

2. 기기에 저장되는 데이터

아래 데이터는 모두 사용자의 기기 내부에만 저장되며, 개발자 서버로 전송되지 않습니다.

  • 보관함(북마크) — 사용자가 저장한 전시/공연/미술관 정보
  • 관람후기 — 사용자가 직접 작성한 글과 첨부한 사진(기기 내 사진 파일 경로로 저장)
  • API 응답 캐시 — 아래 3항의 공공데이터를 다시 받지 않도록 임시 저장하는 캐시

이 데이터는 사용자가 앱 내 "데이터 백업" 기능을 통해 직접 zip 파일로 내보내거나 복원하기 전까지는 기기 밖으로 나가지 않습니다. 앱을 삭제하면 함께 삭제됩니다.

3. 공공데이터 API 이용

앱은 전시/공연 정보를 문화체육관광부·한국문화정보원이 제공하는 공공데이터 API에서 조회합니다. 이 과정에서 사용자의 개인정보를 API에 전송하지 않으며, 단순히 목록/상세 정보를 읽어오기만 합니다.

4. 기기 권한

권한사용 목적
알림(Notifications) 보관함에 저장한 전시/공연의 종료 임박을 사용자에게 기기 내에서 알리기 위함(로컬 알림, 서버 발 푸시 아님)
사진 라이브러리 접근 관람후기 작성 시 사용자가 직접 선택한 사진을 첨부하기 위함. 선택한 사진 외 다른 사진에는 접근하지 않음

5. 광고(AdMob)

앱 하단에는 Google AdMob을 통한 배너 광고가 표시될 수 있습니다. Google 및 광고 파트너는 광고 제공 과정에서 광고 식별자(Advertising ID) 등 기기 정보를 수집·이용할 수 있으며, 이는 개발자가 아닌 Google의 정책에 따라 처리됩니다. 자세한 내용은 Google 광고 정책 및 Google 개인정보처리방침 을 참고해 주세요.

6. 제3자 제공

앱은 수집·저장하는 어떠한 정보도 제3자에게 판매하거나 제공하지 않습니다. (다만 4항에 명시된 AdMob의 광고 식별자 처리는 예외입니다.)

7. 아동의 개인정보

앱은 만 14세 미만 아동으로부터 개인정보를 의도적으로 수집하지 않습니다.

8. 개인정보처리방침 변경

법령이나 앱 기능 변경에 따라 본 방침의 내용이 변경될 수 있으며, 변경 시 이 페이지를 통해 고지합니다.
